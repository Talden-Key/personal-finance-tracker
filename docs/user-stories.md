# Personal Finance Tracker - User Stories

## Project goal
Help individuals record income and expenses, manage budgets, and understand their financial activity.

## User roles

User: Manges their personal finances.
Administrator: Maintains the application and support users.

---
## Epic 1: Account Management
### US-001: Create an account
**As a** new user,
**I want** to create an account,
**so that** my financial information is private and available across devices.

### Acceptance criteria
- The user can register with an email address and password.
- The email address must be unique.
- The passowrd must meet minimum security requirements.
- The user sees a confirmation after successful registration.
- Invalid information displays a clear error message.
